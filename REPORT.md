# Отчёт по лабораторной работе №3

## Данные и подготовка
Для регрессии используется `Student_Performance.csv`, целевая переменная — `Performance Index`. `Extracurricular Activities` преобразуется из Yes/No в 1/0. Для классификации используется `german.csv`, целевая переменная — первый столбец `Creditability`. Категориальные признаки преобразуются в числовые, признаки стандартизируются по обучающей выборке. Разбиение train/test — 80/20, `random_state=42`; классификация использует стратификацию.

## Гипотезы и эксперименты
Проверяется влияние стандартизации на устойчивость градиентного спуска. Линейная регрессия обучается пакетным градиентным спуском с learning rate 0.05 и 800 эпохами; собственная логистическая регрессия — с learning rate 0.1 и 1000 эпохами. Базовые модели: LogisticRegression, дерево решений глубины 6 и KNN с 7 соседями.

## Метрики
**Заполнить автоматически:** выполнить `python run_experiments.py`. Скрипт запишет реальные численные результаты в `experiment_results.json` и обновит этот отчёт. Непроверенные значения намеренно не указаны.

## Выводы
После запуска сравнить ROC-AUC, Accuracy, Precision, Recall и F1. Логистическая регрессия строит линейную границу, дерево может учитывать нелинейные зависимости, а KNN зависит от локальной структуры данных и масштаба признаков. Итоговый вывод следует сделать на основании полученных тестовых метрик.

## Воспроизводимость
Установить зависимости `pip install -r requirements.txt`, положить исходные CSV в эту папку и выполнить `python run_experiments.py`. Используются фиксированный seed 42 и фиксированные параметры моделей.
